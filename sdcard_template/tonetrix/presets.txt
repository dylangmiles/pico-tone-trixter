# Tone Trixter — presets
# =========================================================================
# Flow-style YAML. One preset per block; "---" (or the next "name:") starts a
# new one. Any key you omit inherits the firmware's built-in "default" preset,
# so a preset can be as short as a name + the few things you want to change.
#
#   name:       preset name (shown on screen + selected by config boot_preset)
#   ir:         WAV file in /tonetrix/ir/  (also matches a built-in IR name:
#               "tanglewood" / "garrison"). Use  ir: none  for a dry preset —
#               that turns the whole convolution pipeline OFF. Omitting ir:
#               inherits the default's (which is none).
#   in.on  eq.on  comp.on  out.on   stage enables (1/0, on/off)
#   in.level:   pre-comp input trim, 0.0..8.0 (max raised from 2.0 on 2026-07-24 —
#               with pga at 0 the makeup for the analog gain now lives here)
#   eq.lo:      [freq_Hz, gain_dB]           low shelf
#   eq.mid:     [freq_Hz, gain_dB, Q]        mid peak
#   eq.hi:      [freq_Hz, gain_dB]           high shelf
#   comp:       [thresh_dB, ratio, attack_ms, release_ms, makeup_dB]
#   out.level:  final output level, ~0.0..1.0
#   pga:        ES8388 input PGA gain in dB (0..24, 3 dB steps), set when this preset
#               loads. Passive K&K ~12; active Garrison ~6 (its preamp is hot — +12 clips
#               the ADC on hard strums). Omit to inherit the default (12).
#               ⚠ IGNORED on the Daisy build: the Seed3's TAC5242 has no software gain
#               control, and the front-end level is set by the analogue daughter instead.
#   byp.level:  BYPASS make-up gain, 0.0..8.0, applied ONLY when the chain is bypassed.
#               ⚠ DAISY-ONLY KEY (ignored by the RP2350 parser, like bk.level).
#               Exists so the A/B is LEVEL-MATCHED. Bypass is the raw input; an engaged
#               preset is louder, and for these presets the loudness is the COMPRESSOR's
#               make-up, not out.level. A level difference invalidates an ear A/B --
#               louder simply reads as "better" -- so this lifts the DRY path to meet the
#               wet one instead of turning the preset down.
#               ⚠ Omit or 0 = UNITY (not silence).
#               ⚠ LEAVE THE `default` PRESET AT 1.00. Boot loads it, so the boot state
#               stays a true unity passthrough and is the reference for any measurement.
#   bk.level:   backing-track level, 0.0..2.0, applied when this preset loads.
#               ⚠ DAISY-ONLY KEY. The RP2350 build's parser ignores keys it does not know,
#               so this file stays readable by BOTH pedals — one card, one set of presets.
#               ⚠ Omit (or 0) means "leave the current level alone", NOT silence.
#
# This file reproduces the firmware's three built-in presets. Edit freely —
# the pedal reads it on boot; type `sdreload` over UART to re-read without a
# power cycle.
# =========================================================================

# default — dry baseline: no IR, convolution off. Also the inheritance seed: any preset
# below that omits a key gets it from here. Kept NEUTRAL AND SAFE, not tuned — unity
# in.level, light safety limiting only. attack 1 ms matters: at pga 0 nothing limits
# transients before the DAC, so anything inheriting from here needs a fast attack.
name: default
ir: none
in.on: 1
eq.on: 0
comp.on: 1
out.on: 1
in.level: 1.00
eq.lo: [120, 0.0]
eq.mid: [700, 0.0, 1.0]
eq.hi: [3500, 0.0]
comp: [-18, 3.0, 1, 250, 6]
out.level: 0.60
pga: 0
# ⚠ UNITY, deliberately, and do not change it. `default` is what boots, so the pedal always
# comes up as a true passthrough in bypass -- which makes the boot state the reference for
# any front-end or SNR measurement. Every other preset may lift the dry path; this one must not.
byp.level: 1.00
bk.level: 1.00

---

# tanglewood-slide — passive K&K via the JFET daughter, pga 0. Dialed 2026-07-24: over a full
# slide passage GR runs -6..-14 dB and never hits 0, comp in -5..-17 dBFS comes out -7..-13,
# zero ADC and DAC clips. NO PAD NEEDED — the K&K's worst case (very hard bridge tap) measures
# 0.0 dBFS at the ADC with zero clips. Its hiss is higher than the garrison preset's, and that
# is the IR (flat, passes broadband noise), not the front end — no digital gain can fix it.
name: tanglewood-slide
ir: tanglewood.wav
in.on: 1
eq.on: 1
comp.on: 1
out.on: 1
in.level: 0.75
eq.lo: [150, 3.0]
eq.mid: [800, -3.0, 1.0]
eq.hi: [1500, -2.0]
comp: [-28, 4.0, 1, 300, 16]
out.level: 0.45
pga: 0
# ⚠ OUTPUT LEVELLED 2026-09-09. All three voiced presets now share in.level 0.75, comp make-up 16 dB
# and out.level 0.45, so they are MUTUALLY MATCHED -- switching preset no longer changes loudness.
# byp.level 2.1 is the static chain gain that leaves: -2.5 + 16 - 6.9 = +6.6 dB, so bypass and
# engaged sit level and the stomp changes character only.
# ⚠ 0.45 is NOT arithmetic unity -- unity would be out.level 0.21 (-13.5 dB). It is the builder's ear
# setting, and with a compressor in circuit "unity" is level-dependent anyway: below the -28 dB
# threshold the chain runs at +6.6 dB, above it gain reduction pulls it back. Trim by ear at PLAYING
# level; if you do move it, move byp.level with it or the A/B stops being honest.
byp.level: 2.1
# ⚠ Bed at 1.00 now that the presets are levelled -- it no longer has to duck a hot guitar.
bk.level: 1.00

---

# garrison — active pre-amp, dialed at the bench 2026-07-24 on the JFET daughter at pga 0.
# *** REFERENCE: guitar preamp at 3/4 *** — the guitar's own volume sits ahead of the whole
# pedal, so these numbers only hold at that position. 3/4 is the measured optimum: half->3/4
# buys +8.4 dB of real SNR, 3/4->max only +2.3 dB more and starts clipping the ADC.
name: garrison
ir: garrison.wav
in.on: 1
eq.on: 1
comp.on: 1
out.on: 1
in.level: 0.75
eq.lo: [120, 2.0]
eq.mid: [1000, -2.5, 1.0]
eq.hi: [3500, -1.5]
comp: [-28, 4.0, 1, 250, 16]
out.level: 0.45
pga: 0
# Same levelling as the others -- see tanglewood-slide.
byp.level: 2.1
# ⚠ Bed at 1.00 now that the presets are levelled.
bk.level: 1.00

---

# silent — Yamaha Silent Guitar (SLG), active SRT pickup.
#
# ⚠ THIS IS A CHOSEN TONE, NOT A MEASURED ONE. The SLG has no soundbox, so there is no acoustic
# target to capture a transfer function TO — the usual simultaneous piezo+mic method cannot work
# here, and no amount of mic gain changes that. So it borrows the GARRISON IR and the question
# becomes "which acoustic should this sound like", not "what does this guitar sound like".
#
# ⚠ Garrison rather than tanglewood on purpose: an IR embeds the SOURCE pickup as well as the target
# body, and the garrison IR was captured through an ACTIVE preamp like the SLG's. The tanglewood IR
# came through a passive K&K, so its built-in preamp correction fights an active source harder.
#
# ⚠ TURN THE SLG's OWN SRT BODY MODELLING OFF before judging this. Leaving it on runs two body
# simulations in series — the result is smeared and phasey, not "more acoustic", and it is very hard
# to attribute once you are chasing it with EQ.
#
# ⚠ EQ HERE IS EXPECTED TO MOVE. The residual error is the difference between the Garrison's pickup
# and the SLG's, and the IR cannot correct that — it never saw the SLG's piezo. Starting values are
# copied from garrison; trim by ear with the Garrison as the reference. That is the honest division
# of labour: the IR kills the quack and adds body, the EQ trims the pickup mismatch.
name: silent
ir: garrison.wav
in.on: 1
eq.on: 1
comp.on: 1
out.on: 1
in.level: 0.75
eq.lo: [120, 2.0]
eq.mid: [1000, -2.5, 1.0]
eq.hi: [3500, -1.5]
comp: [-28, 4.0, 1, 250, 16]
out.level: 0.45
pga: 0
# Same levelling as the others -- see tanglewood-slide.
byp.level: 2.1
bk.level: 1.00
